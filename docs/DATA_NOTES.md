# 데이터 이해와 피처 기록

데이터를 살펴보며 확인한 사실, 피처의 의미, 결측값과 누수 위험을 기록한다. 새로운 피처를 추가할 때는 생성식과 예측 시점에 사용할 수 있는 이유를 함께 남긴다.

## 데이터 파일

| 파일 | 역할 | 현재 확인된 크기 |
| --- | --- | --- |
| `data/train.csv` | 학습 입력과 정답 | 1,475,092행 × 49열 |
| `data/test.csv` | 로컬 형식 확인용 평가 입력 | 5행 × 48열 |
| `data/sample_submission.csv` | 제출 양식 | 5행 × 2열 |
| `data/trackman_history.csv` | 2019~2024년 과거 Trackman 로그 | 1,793,078행 × 30열 |

실제 평가 서버의 `test.csv`는 비공개 245,789행으로 교체된다. 로컬 테스트 파일은 실제 점수를 추정하는 용도가 아니라 실행 형식을 확인하는 용도다.

## 주요 컬럼 구분

### 식별자

- `row_id`: 제출 결과와 행을 연결하는 식별자이며 모델 입력에서는 제외한다.

### 정답

- `control_success`: 제구 성공이면 1, 실패면 0이다.

### 피처

피처는 모델이 정답 확률을 예측할 때 참고하는 입력 정보다.

- 경기 정보: `season`, `inning`, `game_type`
- 카운트: `balls_before`, `strikes_before`, `outs_before`
- 점수 상황: `score_diff_home`, `score_diff_pitcher_team`
- 주자 상황: `runner_on_1b`, `runner_on_2b`, `runner_on_3b`, `base_state`
- 선수와 팀: `pitcher_id`, `batter_id`, 팀 ID와 좌우 유형
- 과거 이력: `asof_*` 컬럼

전체 컬럼 설명은 프로젝트 루트의 `data_description.md`를 참고한다.

## 시즌별 정답 비율

| 시즌 | 행 수 | 제구 성공률 |
| ---: | ---: | ---: |
| 2019 | 237,413 | 0.564670 |
| 2020 | 244,087 | 0.532712 |
| 2021 | 247,088 | 0.532762 |
| 2022 | 247,472 | 0.528920 |
| 2023 | 245,525 | 0.499957 |
| 2024 | 253,507 | 0.486105 |

시즌별 성공률이 변하고 있으므로 랜덤 분할보다 시간 순서 기반 검증을 우선한다.

## 기본 검증 분할

- 주 검증: 2019~2023년 학습 → 2024년 검증
- 추가 검증 후보: 2019~2022년 학습 → 2023년 검증

모델과 피처를 비교할 때 같은 검증 기간을 사용해야 한다.

## 현재 베이스라인 피처 처리

- `row_id`만 제외한 47개 입력 컬럼을 사용한다.
- 명시적 범주형 컬럼은 `top_bottom`, `game_type`, `base_state`다.
- 범주형은 `OrdinalEncoder`로 변환한다.
- 수치형 결측값은 중앙값으로 대체한다.

## 피처 후보

아래 항목은 아직 성능 개선이 확인된 피처가 아니라 실험 후보이다.

| 피처 이름 | 생성 방법 | 가설 | 상태 |
| --- | --- | --- | --- |
| `count_code` | `balls_before * 4 + strikes_before` | 카운트 상황을 하나의 상태로 표현 | EXP-002 묶음 적용 |
| `is_full_count` | 3볼 2스트라이크 여부 | 풀카운트에서 제구 패턴이 달라질 수 있음 | EXP-002 묶음 적용 |
| `runner_in_scoring_position` | 2루 또는 3루 주자 여부 | 득점권 상황을 직접 표현 | EXP-002 묶음 적용 |
| `same_hand` | 투수와 타자의 좌우 유형 일치 여부 | 좌우 조합에 따라 결과가 달라질 수 있음 | EXP-002 묶음 적용 |
| `pitcher_batter_success_gap` | 투수 성공률 - 타자 상대 성공률 | 투수와 타자의 과거 경향 차이를 표현 | EXP-002 묶음 적용 |
| `pitcher_recent_success_delta` | 직전 1경기 성공률 - 직전 5경기 성공률 | 단기 변화 방향을 표현 | EXP-002 묶음 적용 |
| `score_pressure` | `abs(점수 차) * li` | 점수와 경기 중요도의 상호작용 표현 | 실험 전 |

피처를 실제로 사용한 뒤에는 연결된 실험 ID와 결과를 이 표에 추가한다.

EXP-002에서는 6개 피처를 한 번에 추가해 2024년 Validation Score가 52.26 상승했다. 이 결과만으로 각 피처가 개별적으로 유효하다고 결론 내릴 수는 없으며, 추후 하나씩 제거하는 실험이 필요하다.

## Trackman 데이터 주의사항

- 메인 데이터와 `row_id` 기준으로 1:1 연결되지 않는다.
- 선수 식별자 매핑 가능 여부를 먼저 확인해야 한다.
- 2019~2024년 과거 기록만 사용할 수 있다.
- 현재 투구의 실제 구종이나 측정값을 사용하면 안 된다.
- 평가 데이터 내부에서 집계한 통계를 사용하면 안 된다.

Trackman 피처는 매핑과 시점 안전성이 확인되기 전까지 모델에 추가하지 않는다.

## 사용 금지 및 누수 점검

- [ ] 현재 투구의 실제 위치나 코스를 사용하지 않는다.
- [ ] 현재 투구의 판정과 결과를 사용하지 않는다.
- [ ] 현재 투구의 실제 구종을 사용하지 않는다.
- [ ] 현재 투구의 Trackman 측정값을 사용하지 않는다.
- [ ] 2025년 Trackman 데이터를 사용하지 않는다.
- [ ] 테스트 데이터 내부의 선수·팀·월별 통계를 만들지 않는다.
- [ ] 테스트 행 순서로 rolling 또는 expanding 피처를 만들지 않는다.
- [ ] 테스트 데이터로 확률 보정값을 계산하지 않는다.
