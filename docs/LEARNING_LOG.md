## STUDY-003 — 피처와 Brier Score 기초 이해

### 피처

피처는 투수가 아니라 영어 `Feature`를 한글로 읽은 말이다. 모델이 정답을 예측할 때 참고하는 입력 정보다.

예시:

- 볼 카운트
- 스트라이크 카운트
- 주자 상황
- 투수의 과거 성공률
- 최근 경기 기록

`control_success`는 맞혀야 하는 정답이므로 피처가 아니라 Target이다.

### 피처 생성

기존 입력을 조합하거나 표현을 바꿔 모델이 패턴을 이해하기 쉬운 새로운 입력을 만드는 작업이다.

예시:

- 3볼 2스트라이크를 `is_full_count`로 표현
- 투수와 타자의 좌우 유형이 같으면 `same_hand = 1`
- 투수 성공률과 타자 상대 성공률의 차이 계산

새 피처는 반드시 현재 투구가 시작되기 전에 알 수 있는 정보로 만들어야 한다.

### Brier Score

```text
Brier Score = mean((예측 확률 - 실제 정답)²)
```

- 실제 정답은 성공 1, 실패 0이다.
- Brier Score는 낮을수록 좋다.
- 틀린 결과를 지나치게 확신하면 오차가 크게 증가한다.
- 정확도와 달리 예측 확률의 품질을 평가한다.

예를 들어 실제 정답이 1일 때:

- 예측 0.8 → 오차 `(0.8 - 1)² = 0.04`
- 예측 0.2 → 오차 `(0.2 - 1)² = 0.64`

### Brier Skill Score

모델의 Brier Score를 평가 데이터의 평균 제구율만 예측하는 기준 모델과 비교한다.

- 원래 Brier Score는 낮을수록 좋다.
- 대회 Brier Skill Score는 높을수록 좋다.
- 평균 제구율만 예측하는 것보다 나아야 양수 점수를 얻을 수 있다.
